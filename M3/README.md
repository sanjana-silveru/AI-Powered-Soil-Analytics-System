# 🌾 Milestone 3 – Recommendation Engine & Farmer PWA

## 1. Overview

Milestone 3 focused on developing the **Recommendation Engine and Farmer Progressive Web Application (PWA)** for the AI-Powered Soil Analytics System.

The main objective of this milestone was to convert the soil analysis results generated in the earlier milestones into **easy-to-understand soil health information, crop recommendations, and soil improvement recommendations**.

A farmer-friendly web application called **Soil Smart 🌱** was developed to provide these results through a simple interface.

Milestone 3 integrates the AI/ML work from Milestone 2 with the recommendation and farmer-facing application.

---

# 2. Objectives

The main objectives of Milestone 3 were:

* To develop a soil recommendation engine.
* To analyze soil nutrient conditions.
* To calculate a soil health score.
* To determine soil health status.
* To identify suitable crops.
* To generate soil improvement recommendations.
* To integrate the CNN soil classification model.
* To develop a farmer-friendly PWA.
* To provide soil image upload and analysis.
* To support multiple languages.
* To maintain previous soil analysis history.
* To test the complete recommendation workflow.

# 4. Knowledge Base

A **Knowledge Base** was created to provide the information and rules required for soil analysis and recommendations.

The system considers the following parameters:

* Nitrogen (N)
* Phosphorus (P)
* Potassium (K)
* pH
* Moisture
* Organic Matter

The values are compared with predefined ranges to determine the condition of individual soil parameters.

The Knowledge Base forms the foundation of the recommendation logic.

---

# 5. Recommendation Engine

## 5.1 Purpose

The Recommendation Engine analyzes soil parameter values and identifies conditions that may require attention.

It evaluates each parameter independently and generates appropriate recommendations.

The system can identify conditions such as:

* Low
* Adequate
* High
* Suitable
* Acidic
* Alkaline
* Needs improvement

---

# 6. Soil Parameter Analysis

The Recommendation Engine analyzes:

| Parameter      | Purpose                             |
| -------------- | ----------------------------------- |
| Nitrogen       | Determines nitrogen condition       |
| Phosphorus     | Determines phosphorus condition     |
| Potassium      | Determines potassium condition      |
| pH             | Determines soil acidity/alkalinity  |
| Moisture       | Determines moisture suitability     |
| Organic Matter | Determines organic matter condition |

The results are then used by the soil health and recommendation modules.

# 8. Soil Health Analysis

A soil health scoring module was developed to convert individual soil conditions into an overall health score.

The score considers the conditions of:

* Nitrogen
* Phosphorus
* Potassium
* pH
* Moisture
* Organic Matter

The resulting score is used to classify the overall condition of the soil.

---

# 9. Soil Health Categories

The application uses the following soil health categories:

```text
80 – 100 → Healthy
60 – 79  → Moderately Healthy
40 – 59  → Needs Improvement
Below 40 → Poor
```

The score and status are displayed to the user through the Soil Smart application.

# 17. CNN Integration

The ResNet-50 CNN model developed during Milestone 2 was integrated into the M3 application.

The Farmer PWA communicates with a prediction API to send the uploaded image to the CNN model.

### CNN Integration Workflow

```text
User Uploads Soil Image
          ↓
Soil Smart PWA
          ↓
FormData
          ↓
Prediction API
          ↓
ResNet-50 CNN
          ↓
Predicted Soil Type
          ↓
Confidence Score
          ↓
Soil Smart PWA
          ↓
Result Display
```

The CNN result is displayed together with the soil analysis information.
